# 🚀 SkillConnect

SkillConnect is a skill-based micro-project platform that connects students with startups, enabling real-world project experience and portfolio building. It bridges the gap between learning and industry exposure by allowing students to work on practical tasks and startups to access affordable, skilled talent.

🌐 Live Demo: https://skillconnect-e3f816.netlify.app

---

## 💡 Project Type

Frontend Prototype (Static Web App)

This project currently demonstrates the UI/UX flow of the SkillConnect platform, showcasing how students and startups interact through micro-projects.

---

## 🌟 Features

- 👨‍🎓 Student profile interface
- 🏢 Startup project posting UI
- 📌 Micro-project listing layout
- 🔍 Skill-based browsing system (UI level)
- 📊 Portfolio showcase design
- ⚡ Responsive and clean frontend design

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Netlify (Hosting)

## 📌 Note

Backend features such as authentication, database integration, project matching, and payments are planned for future development.
